# Interrogacion

**Procedimiento**

El agente deberá identificarse, explicar el motivo del interrogatorio cuando corresponda y realizar preguntas relacionadas con el caso.



**Evidencias**

Las evidencias obtenidas durante la investigación podrán presentarse durante el interrogatorio para contrastar declaraciones.

**Límites**

Queda prohibido utilizar violencia injustificada, amenazas OOC, metagaming o cualquier método que fuerce al jugador a proporcionar información que su personaje no conoce.

{% hint style="danger" %}
No contara con un abogado si se le atrapa infraganti en un delito
{% endhint %}
