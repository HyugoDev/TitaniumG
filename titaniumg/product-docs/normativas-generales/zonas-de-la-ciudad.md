* Todo ciudadano deberá portar su **licencia de armas** cuando lleve un arma consigo.
* Queda prohibido portar o utilizar **armamento de grado 2 y 3** dentro de la ciudad.
* En **barrios bajos**, el armamento permitido dependerá del **nivel de alerta vigente en la ciudad**.

{% tab title="Zonas Seguras" icon="linktree" %}




***

Zonas Gubernamentales: Comisarías, Hospitales, Mecánicos y sedes del Gobierno.&#x20;

* Está prohibido iniciar **actos delictivos, secuestros o agresiones** dentro de estas zonas.
* Se permitirá continuar un rol que se haya iniciado fuera de la zona.
* Queda prohibido realizar actos de **corrupción** dentro de estas zonas.
* No se permitirá la **venta de armas** ni mantener armas visibles de manera injustificada.
{% endtab %}

{% tab title="Zona Roja" icon="tree-deciduous" %}


***

"Zonas de farmeo"

* Antes de iniciar un enfrentamiento, el **bando delictivo** que tenga la intencion de ingresar deberá <mark style="color:$warning;">solicitar disponibilidad</mark> al **otro bando delictivo** involucrado.
* Si el otro bando **no responde** en un plazo de **2 minutos**, se podrá iniciar el tiroteo.
* Si el otro bando responde indicando que <mark style="color:$danger;">**no hay disponibilidad**</mark>, tendrá **1 minuto para retirarse libremente**, sin que pueda iniciarse una persecución durante dicho período.

{% hint style="warning" icon="face-hand-yawn" %}
Si, transcurrido el minuto de retirada, el bando continúa en la zona, se deberá **solicitar nuevamente la disponibilidad**. Si vuelve a responder que **no hay disponibilidad** y permanece en el lugar, podrá iniciarse un **tiroteo por evasión de rol**.
{% endhint %}

* Si el otro bando responde indicando que <mark style="color:$success;">**sí hay disponibilidad**</mark>, se entenderá automáticamente que **acepta el enfrentamiento**, pudiendo iniciarse el **tiroteo en el lugar**.
* La Policía podrá **intervenir en el rol**, anunciándose previamente mediante su comando policial.

{% hint style="danger" icon="chess-pawn-piece" %}
En esta zona se permitirá realizar **cateos completos** sin restricciones, y todos deben ver la luz terminado el cateo.
{% endhint %}

{% hint style="success" %}
Se permitirá el uso de **todo tipo de armamento**.
{% endhint %}

{% tab title="Zona corrupta" icon="hands-bound" %}


***

* La ubicación de estas zonas será **desconocida** para los ciudadanos.
* Se presume que corresponden a puntos destinados al **procesamiento y crafteo de materiales**.
* No será necesario solicitar disponibilidad.
* Queda prohibido el **campeo policial** en estas zonas.

{% hint style="info" icon="gun-squirt" %}
Se permitirá utilizar el armamento correspondiente al **nivel de alerta vigente en la ciudad**.
{% endhint %}
{% endtab %}

{% tab title="Norte" icon="volcano" %}


***

* Se permite el uso de **todo tipo de armamento**.
* Cada organización podrá disponer de un máximo de **2 vehículos blindados**.
* Cada organización podrá utilizar un máximo de **1 helicóptero**.

{% hint style="danger" icon="car-side" %}
Queda prohibido utilizar un vehículo blindado que **pertenezca a otra organización**.
{% endhint %}
